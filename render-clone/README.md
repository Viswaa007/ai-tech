# Render.com Clone - Built with Tailwind CSS

A modern, responsive clone of Render.com cloud platform website built with pure HTML, Tailwind CSS, and vanilla JavaScript.

## 🎨 Features

- **Responsive Design**: Mobile-first approach that works seamlessly across all devices
- **Modern UI**: Clean and professional interface using Tailwind CSS
- **Interactive Elements**: Smooth animations, hover effects, and scroll interactions
- **Fast Loading**: Minimal dependencies, uses CDN for Tailwind CSS
- **SEO Friendly**: Semantic HTML structure
- **Accessibility**: WCAG compliant with proper semantic markup

## 📋 Sections Included

1. **Navigation Bar** - Sticky header with logo and CTA buttons
2. **Hero Section** - Eye-catching banner with main value proposition
3. **Features Section** - 6 key features with icons and descriptions
4. **Use Cases** - Different target audiences (Startups, Enterprises, Students, Agencies)
5. **Pricing Section** - Three-tier pricing model (Free, Pro, Business)
6. **Call-to-Action** - Prominent section to drive conversions
7. **Footer** - Comprehensive footer with links and social media

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework via CDN
- **JavaScript (Vanilla)** - For interactivity
- **Font Awesome** - Icons via CDN

## 📦 Installation

1. Clone the repository
2. Open `index.html` in your browser
3. No build process or dependencies required!

## 🎯 Key Components

### Cards with Hover Effects
```html
<div class="card-hover p-8 rounded-xl bg-gradient-to-br from-gray-50 to-gray-100">
    <!-- Content -->
</div>
```

### Gradient Text
```html
<span class="gradient-text">Your text here</span>
```

### Responsive Grid
```html
<div class="grid md:grid-cols-2 lg:grid-cols-3 gap-8">
    <!-- Items -->
</div>
```

## 🎨 Customization

### Color Scheme
The default color scheme uses purple gradients. To change:

1. Update the gradient colors in `<style>` section
2. Modify Tailwind utility classes (e.g., `bg-purple-600` to your desired color)

### Content
- Edit text in HTML sections
- Update navigation links
- Modify feature descriptions
- Change pricing tiers

### Images
Replace placeholder images with your own:
```html
<img src="your-image-url" alt="Description">
```
